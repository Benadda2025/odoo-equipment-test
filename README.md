# Equipment Management – Odoo 18

Odoo 18 module for managing company equipment, employee assignments, returns, and equipment history.

## 🚀 Getting Started

### 1. Clone the project

```bash
git clone <YOUR_REPOSITORY_URL>
cd <PROJECT_FOLDER>
```
### 2. Start the Docker environment
```bash
docker compose up -d
```

Check that the containers are running:
```bash
docker compose ps
```

### 3. Open Odoo
Open your browser and go to:
```bash
http://localhost:8069
```
